# ⚙️ How to Run the Project

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

## 2. Open the project

```bash
cd YOUR_REPOSITORY_NAME
```

## 3. Run the website

Since this is a static website, you don't need Python, Django or Flask to run the portfolio.

Simply open:

```text
index.html
```

in your browser.

---

## 💡 Recommended Method — VS Code

If you are using VS Code, install the **Live Server** extension.

Then:

1. Open the project in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. Your portfolio will open in the browser.
